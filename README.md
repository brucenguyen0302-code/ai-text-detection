## Task

- **Input:** an English news-style text.
- **Output:** a score whose sigmoid gives the probability that the text was generated by an LLM (label 1) rather than written by a human (label 0).
- **Research question (proposed):** does a supervised detector trained on text from some LLMs still work on text from an LLM it has never seen during training? This is evaluated with a leave-one-generator-out protocol, always with a prompt-grouped train/validation/test split to avoid topic leakage.

## Dataset

*A Comprehensive Dataset for Human vs. AI Generated Text Detection* (Roy et al., 2025, arXiv:2510.22874).
Hugging Face: [`gsingh1-py/train`](https://huggingface.co/datasets/gsingh1-py/train) (CC BY 4.0).
Each row contains a New York Times article abstract (prompt), the human-written NYT article, and articles generated from the same abstract by six LLMs (Gemma-2-9B, Mistral-7B, Qwen-2-72B, LLaMA-8B, Yi-Large, GPT-4o).

The data is **not stored in this repository**; the notebook downloads it automatically.
